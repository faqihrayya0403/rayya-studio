# NexaDigital - Tugas React

Project tugas menggunakan React, Vite, React Router, dan Bootstrap.

## Cara menjalankan

```bash
npm install
npm run dev
```

Buka alamat localhost yang muncul di terminal.

## Halaman
- `/` → Home
- `/team` → Team
- `/contact` → Contact

## Sebelum dikumpulkan
1. Jalankan project dan screenshot Home, Team, Contact.
2. Push project ke GitHub.
3. Invite username mentor sebagai collaborator.
4. Masukkan screenshot + link GitHub ke laporan PDF.
